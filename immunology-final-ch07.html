01 / BIG PICTURE

T 세포는 항원을 어떻게 인식하는가?

T 림프구는 유리된 항원 자체가 아니라 세포 표면에 제시된 항원 펩타이드와 MHC 복합체를 인식한다.

이 장의 Top-down 구조

항원 유입
외부 / 내부→항원 포획·가공
APC 등→MHC에 적재
Class I / II→TCR 인식
CD8 / CD4→면역 반응
살해 / 활성화

T 세포의 주된 기능은 세포 내 미생물 감염을 제거하고 다른 세포를 활성화하는 것이다. 면역 반응을 시작하기 위해 항원은 유입 부위에서 포획된 뒤, naïve T cell이 순환하는 2차(말초) 림프기관으로 모인다.

T 세포가 인식하는 항원의 특징

  1. 펩타이드(Peptides) 형태를 인식한다.
  2. 선형 펩타이드(Linear peptides)를 인식하며, 원래 단백질의 입체 구조는 항원 처리 과정에서 소실된다.
  3. 세포에 결합된 항원(Cell-associated antigens)을 인식하고 용해된 유리 항원에는 직접 반응하지 않는다.
  4. 항원 유래 구획에 따라 MHC I–CD8⁺, MHC II–CD4⁺로 주로 분리된다.

핵심 키워드 (Keywords)

APCT cell receptor (TCR)MHCSubsets of DCPolymorphismImmunodominance

강의자료의 키워드 목록이다. 이 중 Immunodominance는 키워드로 제시되어 있으나, 제공된 정리 내용에는 별도의 상세 설명이 포함되어 있지 않다.

02 / MHC & HLA

MHC의 종류와 구조

MHC는 조직이식 거부반응에 관여하는 유전자군이며, 사람에서는 HLA(Human leukocyte antigen)로 부른다.

MHC Class I · II · III

구분주요 발현 세포제시 항원주로 인식하는 T 세포주요 결과
MHC Class I적혈구를 제외한 모든 유핵세포세포 내부 유래 펩타이드 (Intracellular / cytosolic)CD8⁺ cytotoxic T cell항원을 제시한 표적 세포 살해
MHC Class II전문 APC: 수지상세포, 대식세포, B 세포세포 외부에서 흡수한 펩타이드 (Extracellular)CD4⁺ helper T cell사이토카인으로 다른 면역세포 활성화
MHC Class III분비형 단백질 관련 유전자 영역항원 펩타이드 제시 분자가 아님해당 없음Soluble protein 관련
핵심: Class I은 세포 내부 항원을 CD8⁺ T 세포에, Class II는 세포 외부 항원을 CD4⁺ T 세포에 제시한다.

MHC 다형성 (Polymorphism)

MHC 유전자에는 개인마다 다른 아미노산 잔기가 존재한다. 이 다형성 잔기는 펩타이드 결합 홈(peptide-binding groove)의 형태와 결합 가능한 펩타이드에 영향을 준다.

강의자료에서는 HLA-DR의 다형성 잔기가 주로 β 사슬에 집중되고, HLA-DQ는 α·β 사슬 양쪽에 다형성 잔기가 존재한다고 설명한다.

공동우성 발현과 유전

부모에게서 물려받은 MHC 대립유전자는 세포 표면에 함께 발현된다. 예를 들어 b/b와 k/k 부모 사이의 자식은 b/k가 되어 b형과 k형 MHC를 모두 발현한다.

강의자료의 이식 예시에서는 부모→자식 방향은 공유하는 MHC가 있어 이식 가능성이 있지만, 자식→부모 방향은 자식이 가진 다른 쪽 부모의 MHC가 부모에게 비자기 항원으로 인식될 수 있다고 설명한다.

03 / MHC RESTRICTION

MHC 제한성 (MHC restriction)

TCR은 항원 펩타이드만 단독으로 인식하지 않고, 자기(self) MHC 분자에 결합된 펩타이드 복합체를 인식한다.

개념의 핵심

동일한 항원-X라도 제시하는 세포의 MHC 유형이 T 세포가 인식할 수 있는 자기 MHC와 맞지 않으면 T 세포는 활성화되지 않는다. 즉, T 세포 반응은 항원 펩타이드와 MHC가 함께 결정한다.

항원 펩타이드+자기 MHC→MHC–peptide complex→TCR 인식

이식 거부반응과 MHC

  • 동일한 MHC를 가진 동계 쥐 사이의 피부 이식은 자기(Self)로 인식되어 거부반응이 일어나지 않는 예시로 제시된다.
  • 서로 다른 MHC를 가진 쥐 사이의 피부 이식은 비자기(Non-self)로 인식되어 면역세포가 공격한다.
  • 같은 항원을 주사하더라도 유전적 MHC 유형에 따라 항원 제시 능력이 달라 T 세포 활성화 및 항체 생성 여부가 달라질 수 있다.
04 / ANTIGEN-PRESENTING CELLS

항원제시세포 (APC)와 수지상세포 아형

05 / PROCESSING & PRESENTATION

항원 처리와 MHC 제시 경로

항원이 세포 내 어느 구획에 위치하는지가 MHC class I 또는 class II 경로를 결정한다.

MHC class I vs MHC class II

비교MHC class I 경로MHC class II 경로
항원 기원세포질 내부 단백질 (내인성 항원)세포 외부 단백질 (외인성 항원)
유입·분해 장소세포질에서 ProteasomeEndosome / Lysosome의 산성 소포
펩타이드 결합 장소소포체(ER) 내강후기 Endosome / Lysosome (MIIC)
핵심 매개 분자TAP: 펩타이드를 ER로 수송Invariant chain (Ii), CLIP, HLA-DM
최종 인식 세포CD8⁺ T cellCD4⁺ T cell

MHC class I 경로

  1. 세포질 단백질(바이러스 단백질 등)이 Proteasome에 의해 짧은 펩타이드로 분해된다.
  2. 펩타이드는 TAP을 통해 소포체(ER)로 수송된다.
  3. ER에서 MHC class I 분자에 펩타이드가 결합한다.
  4. MHC I–peptide 복합체가 세포 표면에 발현된다.
  5. CD8⁺ cytotoxic T cell이 이를 인식해 표적 세포를 살해한다.

MHC class II 경로

  1. 외부 단백질 항원이 Phagocytosis 또는 Endocytosis로 유입된다.
  2. Endosome/Lysosome에서 산성 환경과 Cathepsin 등에 의해 펩타이드로 분해된다.
  3. ER에서 합성된 MHC II α·β 사슬은 Invariant chain (Ii)와 결합한다.
  4. Ii는 펩타이드 결합 홈을 막아 ER 내 펩타이드의 오결합을 방지하고 MIIC로 수송되도록 한다.
  5. Ii가 분해된 뒤 남은 CLIP을 HLA-DM이 제거하고 항원 펩타이드로 교환한다.
  6. MHC II–peptide 복합체가 세포 표면에 발현되어 CD4⁺ T cell에 인식된다.

실험 예시: 항원 처리(Processing)가 필요한 이유

  • 세포를 먼저 고정한 뒤 온전한 항원을 넣으면, 항원 섭취·분해가 불가능하므로 T 세포 활성화가 일어나지 않는다.
  • 살아 있는 세포에 온전한 항원을 먼저 처리한 뒤 고정하면, 이미 만들어진 MHC–peptide 복합체가 남아 T 세포 활성화가 가능하다.
  • 세포를 먼저 고정해도 이미 가공된 작은 펩타이드를 넣으면 MHC 홈에 직접 결합할 수 있어 T 세포 활성화가 가능하다.
결론: 온전한 단백질 항원은 세포 내 처리 과정을 거쳐 짧은 펩타이드가 되어야 MHC를 통해 T 세포에 제시될 수 있다.
06 / CROSS-PRESENTATION

교차항원제시 (Cross-presentation)

외부에서 섭취한 항원이 예외적으로 MHC class I 경로를 통해 CD8⁺ T 세포에 제시되는 현상이다.

일반 경로와 예외 비교

OVA 유전자 형질주입세포질에서 합성 → Proteasome → TAPMHC ICD8⁺ T cell

cDC1의 교차항원제시

수지상세포, 특히 cDC1은 세포 외부에서 섭취한 외래 항원을 세포질로 이동시킨 뒤 Proteasome–TAP 경로를 통해 MHC class I에 적재할 수 있다. 이로써 CD8⁺ T 세포를 활성화한다.

핵심 구분: 외부에서 유래했는지만 보는 것이 아니라, 항원이 최종적으로 소포 구획에 있는지 세포질에 있는지를 확인한다.
07 / MHC-RELATED DISEASES

MHC 분자 관련 질환

MHC의 다형성 및 발현 이상은 자가면역질환 또는 적응면역 결함과 관련된다.

강직성 척추염 (Ankylosing spondylitis)

강의자료에서는 환자의 약 90%가 HLA-B27을 보유한다고 제시한다. MHC class I 다형성과 관련된 예시로 정리한다.

중증복합면역결핍증 (SCID)

강의자료는 MHC class I 및 class II 발현 이상으로 병원체에 대한 적응면역이 저하되는 예시를 제시한다. 흉선무형성증과 림프구 표면의 MHC I 결핍에 따른 T 세포 장애, MHC II 결핍증(HLA-D α·β 발현 이상)을 함께 언급한다.

이 부분은 강의자료에 기재된 범위와 표현을 따라 요약했다.

Q1. Which MHC class presents cytosolic peptides to CD8⁺ T cells?

정답: B. MHC class I은 세포질 내부 유래 펩타이드를 CD8⁺ T 세포에 제시한다.

Q2. Which molecule transports cytosolic peptides into the ER for MHC class I loading?

정답: A. TAP이 세포질에서 만들어진 펩타이드를 ER로 수송한다.

Q3. What removes CLIP from the MHC class II peptide-binding groove?

정답: C. HLA-DM이 CLIP을 제거하고 외래 항원 펩타이드가 결합하도록 유도한다.

Q4. Which conventional dendritic cell subset is associated with CD8⁺ T-cell priming in the lecture material?

정답: B. 강의자료는 cDC1은 CD8⁺, cDC2는 CD4⁺ T 세포와 연결한다.

Q5. What is cross-presentation?

정답: A. 세포 외부에서 섭취한 항원을 예외적으로 MHC class I 경로에 실어 CD8⁺ T 세포에 제시한다.
