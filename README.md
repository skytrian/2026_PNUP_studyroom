# MedChem Study - PNUP / PNUP Study Hub

부산대학교 약학대학 학습용 GitHub Pages입니다. 면역학과 의약화학 학습 페이지를 한 곳에서 제공합니다.

## 학습 페이지
- **Study Hub:** https://skytrian.github.io/2026_PNUP_studyroom/
- **면역학:** https://skytrian.github.io/2026_PNUP_studyroom/immunology.html
- **의약화학:** https://skytrian.github.io/2026_PNUP_studyroom/chapters.html

## 주요 기능
- 면역학: Chapter 요약, 단답형 암기 카드, 별표 저장, 복습
- 의약화학: Chapter 18–26 구조 기반 퀴즈, 단계별 학습, 약물 도감·SAR, 약물별 표적·MOA·용도·구조 암기 단서, 챕터별 비교 노트와 기출 핵심 포인트
- 학습 기록은 브라우저의 localStorage에 저장되며 과목별로 분리됩니다.

## 버전 규칙
페이지 버전은 `YYYY.MM.DD.MAJOR.MINOR` 형식을 사용합니다.
- `YYYY.MM.DD`: 마지막 배포 날짜
- `MAJOR`: 호환성이 깨지는 변경 또는 큰 구조 개편
- `MINOR`: 기능 추가·오류 수정 등 일반 업데이트

현재 의약화학 버전은 `2026.10.17.2.4`입니다. 강의자료 `약물리스트.pdf`의 용도·약물표적·작용 양식을 약물 도감과 학습 해설에 추가했고, 약물명에서 세 정보를 고르는 7단계 퀴즈도 강의자료 기준으로 출제하도록 맞췄습니다. Isosorbide dinitrate의 작용기전·구조-SAR·명명법·활성 대사체·nitrate tolerance 및 주요 안전성 포인트를 Chapter 18 도감과 기출 핵심 해설에 보강했습니다. 기출필수 문항 해설 및 관련 약물 카드를 보강했고, 7단계 학습에 `약물명 → 용도·약물표적·작용양식(MOA)` 선택 모드를 추가했습니다. 약물 구조 이미지가 기본 PubChem 주소에서 실패할 경우 PubChem 대체 주소와 NCI/CADD 구조 이미지로 순차 재시도하도록 보완했습니다. Chapter 18–26의 기출 핵심 포인트와 챕터별 비교 노트도 보강했으며, 최근 전체 스크립트 검수에서 메인 학습 스크립트의 중복 `const` 선언을 발견해 수정했고, 3개 인라인 스크립트 모두 문법 파싱 검사를 통과했습니다. 페이지 코드를 수정해 배포할 때마다 해당 페이지의 버전 상수와 버전 JSON 파일을 함께 갱신합니다. 의약화학은 `version.json`, 면역학은 `immunology-version.json`을 기준으로 버전을 확인합니다. 버전 확인 요청에는 캐시 방지 쿼리를 사용하고, 새 버전이 감지되면 버전이 포함된 URL로 페이지를 다시 엽니다.
