❓ 사이트 사용법

약물 구조를 보고 일반명 → 표적 → MOA → 용도를 반복 회상하고, 해설·명명법·암기 핵심으로 복습하는 학습 사이트입니다.

① 학습 시작

  1. 학습(홈) → 원하는 Chapter를 선택하면 해당 Chapter의 학습 단계로 이동합니다.
  2. Stage 1~6 → 구조 인식부터 능동 회상까지 순서대로 학습합니다.
  3. 오답은 해당 약물을 자동으로 다시 출제합니다.
  4. 다음 문제 → 버튼으로 바로 다음 문항으로 이동합니다.

② 플래시카드 / 암기목록

  • 🃏 플래시카드에서 구조를 먼저 보고 카드 뒤집기로 정보를 확인합니다.
  • ☆를 누르면 암기목록에 저장되고 ★ 노란색으로 표시됩니다.
  • 암기목록의 ★를 다시 누르면 해당 약물이 목록에서 삭제됩니다.

③ 해설 보기

정답 후 약물표적·MOA·대표 용도와 함께 명명법 / 명명 유래 / 암기 핵심을 확인할 수 있습니다. 구조 이미지는 클릭하면 확대됩니다.

④ 설정

⚙ 설정을 누르면 현재 문제를 나가지 않고 문제·답안 배치를 변경할 수 있습니다. 설정은 이 브라우저에 저장됩니다.

⑤ 버전 / 초기화

상단의 버전 상태에서 최신 여부를 확인할 수 있으며, 새 버전이 있으면 새로고침으로 업데이트합니다. ♻ 초기화는 학습 진행 기록을 초기화하므로 주의하세요.

문제 / 풀이 위치

❓ 사이트 사용법

시험 대비 구조 회상 학습 페이지의 사용 방법입니다.

1. Chapter 선택

홈 화면에서 Chapter를 선택하면 해당 Chapter의 약물을 학습할 수 있습니다.

2. 학습 단계

  • ① 구조 → 일반명 — 구조를 보고 약물명을 고릅니다.
  • ② 구조 → 약물표적 — 구조와 표적을 연결합니다.
  • ③ 구조 → MOA — 핵심 작용양식을 연결합니다.
  • ④ 구조 → 용도 — 대표 용도를 고릅니다.
  • ⑤ 1:3 종합 매칭 — 일반명·용도·MOA를 한 번에 맞힙니다.
  • ⑥ 구조 → 약물명 타이핑 — 약물명을 직접 입력합니다.

3. 오답 복습

틀린 약물은 학습 중 다시 출제되며, 복습 메뉴에서 오답 우선 복습을 할 수 있습니다.

4. 암기 · 약물 도감 · SAR

암기에서는 플래시카드, 약물 도감 · SAR에서는 전체 약물 정보와 Chapter 18–26의 구조-활성 상관관계를 함께 확인할 수 있습니다.

5. 기타

문제의 약물 구조 이미지는 클릭하면 크게 볼 수 있습니다. ⭐ 표시한 약물은 암기 목록에서 다시 확인할 수 있습니다.
